# ADR-0517 — Spring AI 1.1.x on Boot 3.x SUPERSEDED

**Status:** SUPERSEDED
**Superseded-By:** ADR-0521
**Date:** 2026-06-13
**Supersession date:** 2026-06-13
**Owner:** Principal Engineering

---

## Why This ADR Was Superseded Same Day

This ADR was accepted and immediately superseded within the same session. ADR-0520 established Spring Boot 4.1.x as the mandatory ChaosForge platform baseline, making Spring AI 1.1.x (which targets Boot 3.x only) the wrong choice. Spring AI 2.0.x (requires Boot 4) is the correct version on the new platform.

Retained for institutional memory and ADR audit trail integrity. See ADR-0521 for the operative decision.

---

## Original Decision (Superseded)

Spring AI 1.1.7 on Spring Boot 3.x. Ollama local default. Spring AI 2.0 deferred pending Boot 4 migration.

---

## Why Superseded (Not Reversed)

Supersession, not reversal: the underlying rationale for local-model-default and Ollama remains valid and is carried forward into ADR-0521. Only the version selection changed due to the platform baseline shift. A reversal would imply the original reasoning was wrong; the reasoning was correct given the Boot 3.x assumption — the assumption itself changed.
