# ADR-0505 — Tracing Disabled on Free-Tier Deployed Gateway

**Status:** ACCEPTED — **see Amendment below**
**Date:** 2026-05-20
**Reversal cost:** LOW
**Inherits from:** ADR-0511 ($0 cost ceiling)
**Owner:** Principal Engineering

> **Amendment (2026-07-15, coverage audit; updated 2026-07-16):** the "Local Compose" tracing stack
> this ADR references (Tempo, `management.zipkin.tracing.endpoint`) was **never built** — the current
> `docker-compose_chaosforge.yml` carries no Tempo/Zipkin service. As of 2026-07-16 all three services
> run **Micrometer Tracing (Brave bridge) for MDC/log correlation only**: `trace_id` appears in
> observed log lines and W3C traceparent propagates across the gateway→CP HTTP hop and the CP→exec
> Kafka hop, but **no exporter is on any classpath** — spans are never shipped, so the decision's
> substance (no trace *export* from the deployed gateway) still holds. Export/collector adoption
> remains gated on the OTel stretch (ADR-0507; outcome ADRs 0513/0514 pending).

---

## Context

The deployed Edge Gateway (Fly.io/Railway free tier) has no reachable Tempo or Zipkin collector. Emitting OTLP/Zipkin spans to nowhere buffers them in memory indefinitely. Self-hosting a second free-tier Tempo deployment would consume the second deployment slot and violate ADR-0511's single-service-deployed rule.

---

## Decision

`management.tracing.enabled=false` in the `deploy` Spring profile. Micrometer metrics and structured logs remain fully active on the deployed gateway. Trace inspection requires cloning the repo and running the local Compose stack (where Tempo is wired).

---

## Alternatives

**Emit to a free hosted Grafana Cloud Tempo endpoint:** Introduces a data egress dependency and a third-party account requirement for reviewers. Violates the clone-and-run posture. Rejected.

**Buffer spans in memory, never export:** Memory leak under sustained load. Rejected.

---

## Consequences

**Positive:** No memory overhead from buffered spans on the free-tier deploy. Metrics + logs remain full-fidelity.

**Negative:** Reviewers cannot inspect traces on the live deployed endpoint. Mitigated by local Compose stack documentation.

---

## Implementation Notes

- `deploy` Spring profile: `management.tracing.enabled=false`.
- Local Compose: `management.tracing.enabled=true`, `management.zipkin.tracing.endpoint=http://tempo:9411/api/v2/spans`.
