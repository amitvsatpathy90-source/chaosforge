# ADR-0511 — Free-Tier-Only Deploy; $0/Month Cost Ceiling

**Status:** ACCEPTED
**Date:** 2026-05-20
**Reversal cost:** LOW
**Owner:** Principal Engineering

---

## Context

ChaosForge is a portfolio artifact. Infrastructure cost must not be a barrier to reviewers running it or to the author maintaining it. The constraint is $0/month operational cost.

---

## Decision

Deployment target is **free tier only** (Fly.io or Railway). Cost ceiling is **$0/month**. One service is deployed publicly — the Edge Gateway. The Control Plane and Execution Service run in the local Compose stack only.

Overriding this ADR requires a new ADR-0522+ explicitly noting the monthly cost, the reason it justifies the expense, and a sunset plan.

---

## Alternatives

**Deploy all three services:** Requires paid tiers for two additional services. Violates cost ceiling. Rejected.

**Self-hosted VPS:** Shifts cost to a VPS bill. Not $0. Rejected.

---

## Consequences

**Positive:** Zero ongoing cost. Reviewers can hit a live public URL for the gateway; clone the repo for the full E2E experience.

**Negative:** Control Plane and Execution Service are not publicly accessible. Reviewers must clone and run Compose to see the full system. Documented in README.

---

## Implementation Notes

- Fly.io free tier: 3 shared-CPU VMs, 256MB RAM each. Edge Gateway fits within 256MB with `-Xmx128m`.
- `Dockerfile` for `edge-gateway` must produce an image ≤200MB. GraalVM native image is the target (Boot 4 native image support is improved — see ADR-0520).
